[1m] actually mean by predict the intended input? I mean that if a player presses a button intending to jump, attack, or otherwise perform some sort of action, that action should happen in the game even if the player didn't time it just right. A common application of this principle in platformers is something called coyote time, named after the infamous Wile E. Coyote from Looney Tunes. When players run slightly off of a ledge, they should still be able to jump even if technically the character is no longer on the ground. It prevents that frustration when players accidentally push jump just a tad late, and giving coyote time makes the character feel more responsive. Another application of this principle is input buffering. Input buffering is when a developer stores an input from the player and enacts the action once the character is available to do so. A great example of this is found in Super Smash Bros. If a player is in the middle of performing an attack and presses the button to attack again before the first attack is over, the game stores that input, then performs the action once the character is available to do so. Similarly, in our game Tether Geist, we have input buffering in place for our 
[2m] split mechanic. If the player is in the middle of rejoining with the spirit and presses the split button, the game stores that split action, then starts a new split as soon as the character is done rejoining in the first action. Similarly, if the player presses jump right before landing, the game stores that jump input and tells the character to jump as soon as she touches the ground. There are several other ways to predict intended inputs like adjusting jump height based on how long the player holds a button, reactions to button mashing, and actually intentionally not performing actions that players commonly accidentally press. Whatever it is that you put in your game, you should be designing it such that the character behaviors and actions that happen on screen are as close as possible to what the player is intending to do.
